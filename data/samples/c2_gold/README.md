# C2 gold set (v1, 2026-10-27)

150 real articles from the 14-day window (title + snippet only, links to the source), labelled
by the user (Q-11): `relevant` (a disruption to ports, shipping, factories or freight) and
`types` (one or more `DisruptionType`, `|`-separated; any listed type counts as correct).
Sampled as 16 rules-positive, 50 near misses, 40 Bangladesh mentions and 44 random, so it
over-represents hard cases. Frozen: change it only with a new version.
